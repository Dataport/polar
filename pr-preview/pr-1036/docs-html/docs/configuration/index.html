    Configuration

    POLAR is configured when you create a map. The generic client uses a service register and a configuration object to determine which layers and plugins are available.

    Use the generic client

    For a standard map application, install @polar/polar and import its generic client:

    npm install @polar/polar

    The map container needs an explicit size. Pass either a service-register URL or a service-register array to createMap. The keys in the configuration object enable and configure plugins. The live example below uses the same configuration as the code sample.

    <div id="map" style="width: 100%; height: 600px; position: relative;"></div>

    import { createMap } from '@polar/polar/client'

await createMap(
    'map',
    '../services.json',
    {
        startCenter: [573575, 6018990],
        layers: [
            {
                id: '23420',
                name: 'basemap.de Web Raster Farbe',
                type: 'background',
                visibility: true,
            },
        ],
        layout: 'nineRegions',
        scale: {},
    }
)

    The repository includes a minimal services.json for this example. It defines the 23420 basemap as a WMS background layer. Replace it with your own service register when integrating POLAR into an application. See the API Reference for the complete configuration types and plugin options.

    Choose your path

    Use POLAR in an application

    Start with the generic client and the configuration pattern above. The repository also contains a complete generic client example with a service register, layers, markers, search, pins, and map controls.

    Build a specialized client

    Create a separate client when your application needs its own defaults or domain-specific behavior. The architecture decision Split customer-specific clients into separate repositories explains this boundary.

    Contribute to POLAR

    For changes to the core package, plugins, or shared libraries, continue with the Development guide and Architecture documentation.
