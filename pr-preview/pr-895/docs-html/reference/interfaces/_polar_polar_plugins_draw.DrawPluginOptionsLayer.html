    Optionalid

    id?: string

    ID of the layer to work on. If this ID is contained in the services register, that layer must be a vector layer, and its features will be worked on. If this ID is not contained in the services register, a new vector layer with this ID will be created. If no ID is given, an ID will be generated that fits the prior case.

    Default Value

    A custom ID will be created
